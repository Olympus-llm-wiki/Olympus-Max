# Olympus Max: операционная среда

Начни с [README](README.md) и [команд среды](docs/environment.md).
- Инструменты: `./olympus tool NAME ...`; диагностика: `doctor`.
- Проекты и продолжение работ: `./olympus project ...`, `workspace ...`.
- Перед правками выбранного проекта прочитай его инструкции. Смена cwd не меняет привязку MCP.
- Значимые изменения описывай в OpenSpec. Уже выданное разрешение сохраняется.
- Сохраняй чужую незакоммиченную работу. Проверки: `python3 scripts/test.py`.
- Пользовательские материалы и секреты остаются вне репозитория и архива поставки.
- Секреты доставляются из менеджера секретов в процесс; выводить или записывать значения нельзя.
- Подключения аккаунтов, моделей и приложений проверяются отдельно от наличия CLI.
- Реальный аккаунтный браузер используется только по явной просьбе владельца.
- Медиа обрабатываются через local-media-mining после проверки originals; Whisper запрещён.
- Полный источник сохраняй до анализа. Статусы исторических материалов не являются текущими инструкциями.

Команды памяти доступны через `./olympus memory`. Установщик создаёт новый локальный профиль; управление собственным Docker — через `environment.py runtime`. Внешний Hindsight по-прежнему можно подключить через `starter.py setup`; административные команды клиентского профиля остаются закрыты.

Для инженерной работы используй [olympus-development](.agents/skills/olympus-development/SKILL.md).
Навыки Matt Pocock, OpenSpec и ECC выбираются по задаче; один процесс ведёт этап.
Адаптеры: [домен](docs/agents/domain.md), [задачи](docs/agents/issue-tracker.md),
[роли](docs/agents/triage-labels.md). Названия Claude slash-команд интерпретируй
через реально доступные инструменты своего агента. Квоты покрытия/число ревью
из общих шаблонов соизмеряй с контрактом конкретного проекта. Модельных операций
при установке среды нет.
