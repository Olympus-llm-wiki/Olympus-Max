# Роли задач

Локальные обозначения для навыков; внешние метки не создаются.

| Роль | Значение |
|---|---|
| needs-triage | Требует первоначального разбора |
| needs-info | Не хватает конкретного основания или ответа |
| ready-for-agent | Требования достаточны для работы в разрешённой области |
| ready-for-human | Нужна конкретная проверка или решение владельца |
| wontfix | Зафиксировано решение не выполнять |

Если роль нужна, укажи её у соответствующего среза в OpenSpec `tasks.md`.
Чекбокс задачи отмечается только после выполнения и проверки; роль не заменяет его.
Для исследовательских вопросов wayfinder `claimed` и `resolved` описывают состояние
работы над вопросом, а не разрешение изменить продукт.
