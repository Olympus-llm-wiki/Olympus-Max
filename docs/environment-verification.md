# Проверка выпуска 0.3.0

Проверено 20.09.2026 на macOS Apple Silicon с Python 3.12.13.

| Проверка | Результат |
|---|---|
| Max | 587 тестов, без пропусков |
| Lite | 148 тестов; один native-restore тест относится только к Max |
| Общий установщик и архивы | 10 тестов: изоляция, повтор, конфликт конфигурации, manifest, исключение личных файлов |
| Медиапакет | 88 тестов, синтетические внешние ответы |
| Реальная установка | Max в отдельном окружении; Lite из распакованного архива в пути с пробелами |
| Serena обеих редакций | MCP initialize/tools/list и реальный get_symbols_overview Python-файла; 14 инструментов |
| Max Docker | Отдельные volumes, скачанные закреплённые модели, здоровый API; без ключа 401, с ключом 200 |
| Ключ runtime | Значение отсутствует в Config.Env обоих контейнеров; доставка stdin/FIFO |
| Чистые архивы | Verifier, новая конфигурация, project/workspace и CLI редакции проходят после распаковки |

Для Lite переиспользован кеш общедоступных зависимостей; venv, авторизации и
пользовательские материалы не копировались. Вызовов моделей при этих проверках нет.
Native логины, системные окна установки и второй физический Mac требуют владельца;
они не выдаются за проверенные. Тестовый Docker runtime после проверки остановлен.

RED/GREEN: сначала отсутствовал менеджер (семь новых тестов); после реализации
все прошли. Живой запуск выявил default consolidation reservations больше числа
слотов. Регрессия воспроизведена тестом и исправлена явной reservation=0; повторный
запуск и аутентификация прошли. Затем добавлены проверки целостности архивов.

Проверка секретов: реальные credentials в составе поставок не обнаружены. В Max
срабатывания gitleaks проверены: SHA-256 файлов secret_scan в manifest и заведомо
синтетические строки PEM в тесте сканера. Bytecode/cache не входят в архив.

Повтор: `python3 scripts/test.py`, `python3 scripts/verify-distribution.py`.
Живой MCP: `python3 scripts/verify-live-tools.py --output /absolute/new-proof.json`.
