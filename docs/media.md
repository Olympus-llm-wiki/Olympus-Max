# Медиа-инструменты

Актуальные исходники runner и пакета reel-analysis поставляются вместе с
[навыком](../.agents/skills/local-media-mining/SKILL.md). Для выбранного сценария:

```bash
./olympus extras media
./olympus tool reel --help
./olympus tool media plan /absolute/video.mp4
```

ffmpeg/ffprobe устанавливает Install.command. Antigravity CLI устанавливается командой extras media; вход владельца
проверяется отдельно через doctor. Подписочный runner не включает дополнительные
AI-кредиты. Новые paid API и переключение провайдера требуют отдельного решения.
Результаты и originals хранятся вне Git; наличие SUCCESS не подтверждает полноту.
Тексты, таймкоды и визуальные наблюдения проверяются по материалу.
