# Общий поиск Max

```bash
python3 max.py search "Вопрос по источникам"
python3 max.py search "Вопрос по источникам" --local-only
python3 max.py search "Вопрос по источникам" --scope personal
```

По умолчанию поиск охватывает зарегистрированные области текущего банка. Имя автора в вопросе влияет на ранжирование, а фильтр --scope/--package добавляется только при явном ограничении. Импорт и retain поиск не запускает. Локально доступны подходящие pending и archive-only источники, поэтому отказ Hindsight не скрывает сохранённый original.

`results` содержит локальные выдержки и происхождение; `semantic_results` — native recall. `catalog` — навигационные карточки, если пользователь зарегистрировал свой каталог; чистый стартер не включает каталог автора. `coverage` показывает области, ошибки и пропуски, `absence_proven` остаётся false. Не найдено не означает не существует. `--include-discussions` отдельно включает архивные обсуждения без превращения их в инструкции.

Проверяются hashes и барьеры отзыва/восстановления. Удержанный research-отчёт не возвращается через локальный fallback. Пределы: 64 MiB на версию, 256 MiB за проход, 1–100 результатов, не более четырёх семантических областей. Timeout каждого native запроса по умолчанию 30 секунд; используйте --timeout для другого допуска. RU/EN расширение лексики ограниченное, его группы видны в ответе.

Поиск использует состояние и банк starter.local.json. Административные команды внешнего runtime по-прежнему закрыты. Для первого поиска сохраните источник через capture-file; `--local-only` не требует работающего сервера или API key.
