# Контекст для инженерных навыков

До исследования читать `AGENTS.md`, релевантные разделы `README.md`,
`openspec/specs/` и выбранный `openspec/changes/<change>/`. Документы в `docs/`
уточняют соответствующий контракт. Состояние и текущий код проверяются отдельно.

`CONTEXT.md` и `docs/adr/` читать по теме, если они существуют. Не создавать их
заранее ради установки навыков. Согласованные термины и обоснования изменений
сначала сохранять в соответствующих OpenSpec-артефактах; отдельный словарь или ADR
нужен только при самостоятельной пользе, без конкурирующей редакции решения.

Память читать через Olympus CLI. Найденное воспоминание является источником с
происхождением и статусом, а не автоматически действующей инструкцией.
Старые правила и предложения не становятся текущими от повторного упоминания.
Гриллинг уточняет решения владельца; проверку доступных фактов выполняет агент.
OpenSpec Explore и grilling — альтернативные режимы обсуждения, не два обязательных
последовательных опроса. Инструкции владельца определяют желаемую глубину и темп.
