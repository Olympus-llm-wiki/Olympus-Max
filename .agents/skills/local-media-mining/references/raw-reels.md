# Пакетное извлечение сырья из коротких видео

Этот маршрут нужен, когда результатом служат только наблюдаемые источники: речь,
текст на экране, сцены и видимые события. Он делает один вызов Gemini на файл,
не добавляет интерпретацию стиля и выполняет очередь строго последовательно.

Исполняемая команда находится в `packages/reel-analysis`. Манифест версии 1 содержит
`corpus_id` и `items`; для каждого item обязательны `id`, абсолютный `path`, `sha256`
и `duration_s`. Необязательный `prior_result` переносит уже принятый результат того же
файла, промпта и модели без нового вызова.

```bash
cd /absolute/olympus/packages/reel-analysis
uv run --no-sync reel raw-plan \
  /absolute/corpus/manifest.json --output /absolute/corpus/extraction
uv run --no-sync reel raw-run \
  /absolute/corpus/manifest.json --output /absolute/corpus/extraction \
  --model gemini-3.8-flash-high --prompt-profile compact-v2 --continue-on-error
uv run --no-sync reel raw-status \
  /absolute/corpus/manifest.json --output /absolute/corpus/extraction
```

Runner до вызовов сверяет все хеши. Готовые результаты переиспользуются только при
совпадении файла, модели, промпта и схемы. По умолчанию неуспешный или неизвестный исход
останавливает очередь и сохраняет raw попытки. Для исследовательского корпуса
`--continue-on-error` заносит его в `summary.json.unprocessed` и без повтора переходит к
следующему; явный повтор делается отдельно через `--retry-failed`. Один batch защищён
файловым lock от второго worker. Долгий `raw-run` запускай в именованном tmux.
При возобновлении unknown сначала восстанавливается из сохранённого terminal raw без
нового вызова, если среди служебных рассуждений есть один полный JSON-объект с точными
верхнеуровневыми ключами результата. Фильтр-отказ, повреждённый объект и несколько
подходящих объектов не принимаются.

`summary.json` даёт число ready/failed/unknown/pending, покрытие каждой модальности,
список технически готовых, но неполных ответов, суммарные токены и количество наблюдений.
Каждый `runs/<id>/result.json` остаётся `draft_unverified`: таймкоды примерные, а полнота
речи, текста и быстрых визуальных изменений требует выборочной проверки по оригиналу.
Полный raw NDJSON и scope audit лежат в соответствующей `attempt-N`.

Для повторного прохода после output-limit и раздутых пословных captions используй
`compact-v2`: речь остаётся дословной, captions объединяются во фразы, а обычные жесты
не создают события. `detailed-v1` сохраняет прежний контракт. Профили имеют разные
отпечатки; не смешивай их результаты в одном output directory.
