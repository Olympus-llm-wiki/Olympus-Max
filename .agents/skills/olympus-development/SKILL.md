# Разработка через Olympus

1. Из корня поставки вызови `./olympus project show <имя>` и
   `workspace resume --project <id>`. Для новой работы используй prepare/start.
   Прочитай выбранные инструкции; разбери changes/issues/overlaps до правок.
   Готово, когда известны точный ресурс, каталог и требования.
2. Выбери одну применимую процедуру: OpenSpec, Matt Pocock или bundled ECC.
   Сохраняй уже выданное разрешение владельца. Готово, когда определены проверяемые
   критерии текущей задачи; общие шаблоны не создают новые approval gates.
3. Выполни изменения в выбранном каталоге; checkpoint сохраняется через ops.py.
   Проверь связку cwd/MCP отдельно. Готово, когда код проверен против требований.
4. Используй scripts/checkpoint_guard.py с **явным --state** каталога operations
   этой установки (путь содержится в .olympus-local.json, добавь `/operations`).
   Квитанции размещай вне выбранных репозиториев. Передай check реальные argv/cwd,
   затем finish — свежие квитанции. При оставшейся работе сохрани checkpoint.
   Готово, когда следующая задача может возобновить работу и найти результаты.

[Карта проектов](../../../docs/project-workspaces.md) и
[контракт проверок](../../../docs/ecc-development.md) описывают форматы команд.
Данные памяти Max и библиотека Lite не требуются для исполнения инструментов.
