# Olympus Max starter

Начни с [README](README.md). Это клиентский профиль для отдельного Hindsight API.

- Запускай команды через `python3 max.py`, чтобы использовать отдельное состояние и банк этого стартера.
- Настройка — `python3 starter.py setup`; живой read-only контроль — `python3 starter.py doctor --live`.
- Не копируй чужое состояние, OAuth store, API keys или материалы владельца в шаблон.
- Секреты поступают из менеджера секретов в окружение процесса; значения не выводятся и не сохраняются в git.
- Сохраняй полный источник до анализа. Отделяй синтез, обсуждение, оценку и подтверждённое решение.
- Существенный синтез оформляй пакетом research. Готовность к проверке не означает истинность вывода.
- Learning хранит наблюдения. Для активации изменения нужны точные подтверждения владельца и успешная проверка случаев; не фабрикуй их.
- Этот профиль не управляет внешним сервером. Не обходи запрет административных команд прямым вызовом внутренних модулей.
- Новые пользовательские данные находятся вне репозитория. Примеры и тесты — только синтетические.
- Проверка разработки: `PYTHONPATH=src python3 -m unittest discover -s tests -q`.
