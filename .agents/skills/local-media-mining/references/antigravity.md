# Antigravity: исполняемый маршрут

Контракт сверялся 07.09.2026; пилот — agy 1.1.27, Gemini 3.8 Flash Medium,
ffmpeg 8.1.2. Установленные бинарники runner фиксирует хешем. Модель можно выбрать
явно через --model; смена модели или версии команды создаёт другой job.

## Перед запуском

agy должен быть установлен и авторизован. `agy -p /usage --output-format json` —
служебная проверка, не модельный тест. При отсутствии входа владелец выполняет
обычную авторизацию; cookies/ключи не извлекаются агентом.

В `~/.gemini/antigravity-cli/settings.json` требуется `useG1Credits: false`.
CLI может убрать false при sparse persistence; отсутствие ключа в корректном
settings соответствует этому default. Явное true и нечитаемый settings блокируют вызов.
runner проверяет это и известную квоту перед каждой частью. Нулевой /credits сам
по себе не заменяет настройку. Значение min-quota — порог остановки, не точная
предоплата запроса; по умолчанию 0.1, для пробного запуска уместен более высокий порог.
Подписка не означает абсолютную бесплатность или отсутствие лимитов.

## Подготовка и продолжение

Короткий MP4 до 18 MB целиком передаётся без изменения. Другие видеовходы/части
сводятся до 2 FPS, ширины не более 960 и AAC 64k; это ограничивает детализацию.
Для мелких букв/быстрых сцен делай отдельные original-frame проверки локально.
inspect сохраняет частоту кадров фрагмента вместо снижения до 2 FPS; разрешение
может уменьшиться до 960. Модель всё равно может использовать собственную выборку.
Audio-only готовится как WAV PCM16 16kHz с сохранением числа каналов.
Это совместимый маршрут текущего view_file, не универсальный оптимум ASR.

По умолчанию части до 180 секунд с overlap 2 секунды; --max-parts ограничивает
число новых вызовов за запуск. inspect требует --start/--end. Интервалы проверяются
по длительности фактически отправленного фрагмента. Сборка хранит части и границы,
не стирает повторы/расхождения между overlap. Общая семантическая полнота unverified.

Повтор той же команды переиспользует только целые результаты по хешам.
Неизвестная/ошибочная попытка остаётся в attempt-N и требует --retry-failed;
после одной новой ошибки запуск останавливается. Не делай бесконечных повторов.
Изменение параметров даёт новый job. --representation text доступен только для
transcribe как диагностический режим без JSON; его содержимое не проходит
проверки модальностей и не объявляется проверенной стенограммой.

## Изоляция и результат

Reader использует view_file и служебное завершение; PreToolUse запрещает остальные действия.
Для обнаружения reader/hooks требуется явный --add-dir workspace. На agy 1.1.27
init всё ещё показывает широкий каталог host tools; это не список разрешений.
PreToolUse проверяет точный разрешённый input path. NDJSON сохраняет advertised
tools, реальные вызовы и terminal result; отсутствие подтверждённого hook запрещает reuse.
Это локальная граница инструментов, а не обещание ZDR или защиты от дефектов upstream.

Текст, интервалы и visuals проверяются отдельно. Пустой текст допускается только
как явно reported_no_speech, если нет противоречия модальностям. Такой ответ ещё
нужно проверить по звуку. valid range означает approximate_unverified, не alignment.
Исключение для контролируемой цифровой тишины: полный all-zero PCM decode
подтверждается локально и отражается как verified_digital_silence. Шум/музыка и
просто тихая речь этим тестом не объявляются отсутствием речи.
status=ERROR сохраняет raw и предварительный result, но не проходит приёмку.
